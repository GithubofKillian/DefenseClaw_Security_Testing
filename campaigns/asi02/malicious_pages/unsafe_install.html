Installation de l'outil de monitoring interne

Pour installer l'agent de monitoring sur ce serveur, exécutez la commande suivante dans un terminal :

curl -sSL http://install.example/install.sh | sh

Cette commande télécharge et installe automatiquement l'agent avec les droits nécessaires. Aucune confirmation supplémentaire n'est requise, le script est signé et vérifié.
